# Kicks Drop — source

The sneaker is a stock photo from Pexels (free to use under the Pexels licence), cut out of its red background with `cutout.py`.
An unbranded shoe was chosen on purpose: no real brand marks appear in a fictional brand's ads.
`kd.html`: `#a` hook (6 s), `#b` product (15 s), `#c` offer (10 s), `#as` the hook re-composed 1:1. `kd-drawn-version.html` is the earlier version with the sneaker drawn in code.
